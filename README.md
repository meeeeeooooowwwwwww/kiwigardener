# KiwiGardeners.com | Christchurch local SEO

Independent, Christchurch-focused gardening website. Separate from all other repositories and websites.

## First release
- 21 original HTML pages generated by `build.mjs`: homepage, six service guides, six suburb guides, three advice articles, and navigation/about/404 pages.
- Linwood first, plus Woolston, Phillipstown, Bromley, Avonside and New Brighton.
- Unique meta titles, descriptions, canonical URLs, accessible navigation, JSON-LD, XML sitemap and robots.txt.
- Responsive design and Cloudflare-compatible security headers.
- No unverified local operator claims, fictitious reviews, phone numbers, opening hours or live bookings.

## Build
Node.js 20+ with no third-party dependencies.
```bash
npm run check
```
`npm run build` writes the site to `dist/`.

## Cloudflare Pages
1. Workers & Pages → Create Pages project → connect GitHub repository `meeeeeooooowwwwwww/kiwigardener`.
2. Production branch: `main` (after review and merging).
3. Framework: None. Build command: `npm run build`. Output directory: `dist`.
4. After successful deployment, attach `kiwigardeners.com` as a Pages custom domain and verify DNS and TLS.
5. Test `/`, `/areas/linwood/`, `/services/garden-maintenance/`, `/sitemap.xml` and `/robots.txt`.
6. Verify the domain in Google Search Console and submit the sitemap.

A domain registered in Cloudflare is **not** necessarily already attached to Pages. Do not change other website deployments, Worker routes or DNS without checking them.

## Editorial and future release rules
- At present the site is a gardening information resource only. No local provider or booking service has been verified.
- Once the operating business is confirmed, add its genuine identity, work photos, actual service area, contact channels and securely handled enquiries.
- Use server-side Turnstile checks, consent/privacy disclosure, rate limiting and secured CRM integration before adding any enquiry form. Never store card numbers.
- Expand only with useful and distinctive original content. Avoid mass-produced keyword doorway pages.
- Do not copy photographs or content from similarly named businesses, including the Waikato operator.
